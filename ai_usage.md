# AI Usage Documentation

## Purpose

AI tools were used as supplementary resources during the development of the MicrobeID project. Their use was intended to assist with programming, troubleshooting, and understanding bioinformatics and machine learning concepts.

## How AI Was Used

AI assistance was used for:
- Developing and troubleshooting Python code in Google Colab.
- Understanding machine learning methods and image feature extraction.
- Explaining errors and suggesting possible corrections.
- Organizing the project workflow and improving documentation.
- Editing written sections of the project report.

## Human Review and Verification

All code was run and its outputs were reviewed during development. Dataset image counts, species and growth-medium labels, duplicate screening, and plate-level training and testing assignments were checked against the original dataset files and manifests. AI suggestions were evaluated and adjusted as needed throughout the project.

## Limitations

AI-generated suggestions may contain errors or assumptions that do not apply to the dataset. Therefore, AI assistance was not treated as a substitute for checking the code, data, or results.

## Responsibility

The project design, decisions about data processing, interpretation of results, and final project content were reviewed and approved by the student.
